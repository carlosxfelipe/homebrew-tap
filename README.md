# homebrew-tap

Personal Homebrew Tap repository of Carlos Felipe for distributing macOS applications.

## Available Casks

### Thunder ⚡
File manager written in Swift with SwiftUI.

```bash
brew install carlosxfelipe/tap/thunder
```

### mov2gif 🎥
Convert .mov files to .gif.

```bash
brew install carlosxfelipe/tap/mov2gif
```

### LiveWallpaper 🌇
Lightweight, native macOS menu bar app to set custom gradients and looping videos as your desktop wallpaper.

```bash
brew install carlosxfelipe/tap/live-wallpaper
```
